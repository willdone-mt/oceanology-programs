## Levels

These programming levels below are used to labels and notes certain program about their code usability.

1. **General**  
    the codes in the program are used in general dicipline/occasions, thus not specifically intended for that topic.
    The codes in the program just to help little things
2. **Intermediate**

3. **Specific**  
    The code in the program are made specifically for certain discipline/topic, but still can be used in other program only with extensive study about it.
4. **Hardly Specific**  
    The code in the program are made specifically for that discipline/topic and cant be used for other than that
