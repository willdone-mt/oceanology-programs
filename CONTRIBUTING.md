# Contributing Guidelines

This repository is intended to help other students or common users understand the ocean and life in it via programs, even also understanding the programs itselves! Therefore, all(most) of the codes, syntaxes, functions, programs or anything you call it, are free and open-source. However, i also need your help to improve ourselves and these codes **by contributing to this repository**.

## General

# Code
The codes are free and open-source, download separately as you want!

but if you found it not working, you can either:
- Tell me via opening an Issue; or
- Fix it up yourself and keep it; or
- Fix it up yourselves and tell me (and others) about it:
  - by opening an Issue; or
  - by opening a pull request via **forking**

# Pull Requests
As a non-collaborator, you have to **fork** this repository and make changes there to open a **pull request**. Myself considered this as a long waay to change the codes.

for shorter method, you can open an issue about that.
